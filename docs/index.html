// What we're building

Not another Western ERP with an India plugin.

🧾

Intelligent GST Engine

Automatic Place of Supply detection across all 38 Indian states. Intra-state transactions get CGST+SGST split. Inter-state gets IGST. Zero manual calculation.

// Maharashtra → Karnataka = Inter-state
const result = calculateGST({
  supplierStateCode: "27",
  customerStateCode: "29",
  items: [{ gstRate: 18, unitPrice: 50000 }]
});
// → totalIgst: ₹9,000 | grandTotal: ₹59,000
📒

Double-Entry Ledger

Every invoice automatically posts balanced journal entries. Debit Accounts Receivable, credit Revenue + Output Tax. Always balanced. Always accurate.

1200 Receivable ₹59,000 DR
4000 Sales Revenue ₹50,000 CR
2130 Output IGST ₹9,000 CR
Balance ✓ Matched
