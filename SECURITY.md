# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 0.1.x   | ✅ Current (dev)   |

## Reporting a Vulnerability

If you discover a security vulnerability in Lekhva ERP, please report it responsibly.

**Do NOT open a public issue for security vulnerabilities.**

Instead, email us at: **keshavagarwalbiz@gmail.com**

### What to include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response Timeline:
- **Acknowledgement**: Within 48 hours
- **Assessment**: Within 1 week
- **Fix & Disclosure**: Coordinated with reporter

Thank you for helping keep Lekhva ERP secure! 🔒
